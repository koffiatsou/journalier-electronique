# Parcours V75 — de l'agenda au PIA

> Pour qui : tout agent qui connaît le « Journalier » papier et le « PIA » Word.
> Principe : **on encode une fois dans la séance** ; le même contenu alimente le Journalier Word, la préparation de réunion et le PIA.

## 1. Agenda

- Planification récurrente (par exemple « chaque vendredi à la 2e heure, mathématiques avec l'élève »), jusqu'à la fin de l'année scolaire.
- Les matières proposées pour un élève sont **celles de son dossier**. Le dossier accepte de nouvelles matières (« + Ajouter la matière … »).
- Statuts d'un créneau : **Planifié → Réalisé** (automatique dès qu'une séance est encodée), **Annulé**.
- Motifs d'annulation : élève absent, co-enseignement (élève absent mais l'agent va en classe → **Réalisé** avec mention d'absence), professeur absent, **agent du pôle absent**, autre motif.

## 2. Séance

Deux zones, comme la feuille papier.

| Zone | Contenu | Carte |
| :--- | :--- | :--- |
| Partie pédagogique | Créneau, objectif de la leçon, contenu vu en classe, mon objectif, mon intervention | 1. Créneau et partie pédagogique |
| Partie orthopédagogique | Ce que l'agent observe et met en place | 2. Fonctionnement observé · 3. Compétence travaillée · 4. Ce qui a aidé · 5. Transfert · 6. Suite |

Échelle unique pour les observations : **Partiellement / Suffisamment / Totalement**. Aucun niveau n'est coché d'office. Après le choix, seul le niveau choisi reste affiché ; l'appui sur ce niveau rouvre les trois choix. L'enregistrement est refusé tant qu'une observation cochée n'a pas de niveau.

Effet d'une aide (échelle séparée, car on mesure l'aide, pas l'élève) : **Aucun effet / Effet partiel / Effet positif**.

Statut de présence (en haut de la séance) :

| Statut | Conséquence |
| :--- | :--- |
| Présence normale | Séance complète |
| Élève absent — co-enseignement | Partie pédagogique conservée (contenu vu en classe), pas de partie orthopédagogique |
| Élève absent — séance non tenue | Une ligne d'absence |
| Professeur absent / cours annulé | Une ligne d'absence |
| Agent du pôle absent | Une ligne d'absence, non imputée à l'élève |

Seules les séances avec l'élève présent comptent dans le taux de présence de l'élève.

## 3. Journalier (anciennement « Historique »)

- Rapports & PIA → onglet **Journalier**.
- Période : **Année scolaire** (par défaut), **État à ce jour** (pour la direction), semaine, mois, dates libres. La période s'applique à la liste, aux statistiques et à l'export.
- Chaque séance s'affiche comme sur le papier (mêmes intitulés que le Word).
- Bouton **Exporter le Journalier (Word)**, avec la case « Sans le nom de l'élève ».

## 4. Réunion

- Onglet **Réunion** : synthèse en langage simple, matière par matière (points d'appui, points à travailler, compétence travaillée, aides qui ont fonctionné) et mention des absences.
- Onglet **Propositions** : propositions automatiques d'objectifs, à accepter, refuser ou modifier (mécanique conservée de V74).

## 5. PIA

- Onglet **PIA annuel** : cases du modèle officiel, procès-verbal, aménagements.
- Le bouton **Exporter le PIA officiel (Word)** est visible en haut (réunion de décembre ou fin d'année, identifié ou non).

## 6. Mis de côté

- **Rapprochement avec le référentiel WBE** (repères et indicateurs d'apprentissage) : masqué dans la séance, car pas assez fiable hors mathématiques. Le code et les données restent ; ils seront retravaillés avec les référentiels fournis par les utilisateurs.
