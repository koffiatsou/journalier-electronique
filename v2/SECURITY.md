# Sécurité (V2)

La référence de sécurité est le fichier [`SECURITY.md` à la racine du dépôt](../SECURITY.md). Il est gardé à un seul endroit pour ne pas se contredire.

Résumé : données d'élèves chiffrées sur l'appareil, aucun serveur, synchronisation vers le OneDrive de l'agent seulement, CSP stricte, dépendances réduites. Pour signaler un problème : prévenir le propriétaire du dépôt, sans jamais publier de données réelles.
